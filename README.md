# Finance Tracker 
A tool to prevent impulse buying. Currently a prototype.
# Featuers
- adding 1000 php to the balance generates a npc.
- subtracting 1000 php to the balance deletes a random npc.
- user can make the camera follow an npc by clicking them.
- user can rename an npc.
- user can set budgets, a progress bar is visible to show how close user is to reaching the budget limit.
- custom camera hook.
- custom npc movement hook.
<br> All data is saved in localstorage.
